# 🤖 AI Interview Preparation Platform

An AI-powered Interview Preparation Platform built using **Python, Flask, SQLite, HTML, CSS, and Gemini AI**. 
The platform helps users prepare for HR, Technical, and Coding interviews while also providing AI-based resume analysis with ATS scoring.

---

## ✨ Features

### 👤 User Authentication
- Secure Signup & Login
- Password Hashing
- Session Management
- Logout Functionality

### 💼 HR Interview
- AI-generated HR questions
- One question at a time
- Skip Question
- AI Evaluation
- Score & Feedback
- Strengths & Weaknesses
- Improvement Suggestions

### 💻 Technical Interview
- AI-generated Technical questions
- Question numbering
- Skip Question
- AI Evaluation
- Detailed Feedback

### 👨‍💻 Coding Interview
- AI-generated Coding questions
- Large code editor
- Skip Question
- AI Code Evaluation
- Complexity Analysis
- Improvement Suggestions

### 📄 AI Resume Analyzer
- Upload PDF Resume
- AI ATS Score
- Skills Found
- Missing Skills
- Resume Improvement Suggestions
- Interview Readiness Analysis

### 📊 Dashboard
- Continue Interview
- Restart Interview
- Progress Tracking
- Modern User Interface

## 🚀 Installation

Clone the repository

```bash
git clone https://github.com/your-username/AI-Interview-Preparation-Platform.git
```

Move into the project folder

```bash
cd AI-Interview-Preparation-Platform
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
